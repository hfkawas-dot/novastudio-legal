NovaStudio Autopost - Privacy Policy

Last updated: 2026-11-02

NovaStudio Autopost is an internal tool used by NovaStudio to publish the studio's own videos to the studio's own TikTok, YouTube and Instagram accounts. It is not offered to the public.

Data we collect

We do not collect, store, sell or share personal data from any user or visitor. The tool only handles the studio's own videos and captions, and OAuth tokens for the studio's own accounts. Tokens are stored locally on the studio's computer and are never transmitted anywhere except to the respective platform's official API.

YouTube API Services

NovaStudio Autopost uses YouTube API Services to upload the studio's own videos to the studio's own YouTube channel. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The only YouTube data the tool handles is the OAuth token for the studio's own channel (scope youtube.upload) and the ID of each video it uploads. It does not read, store or share any other YouTube user data.

Third parties

Videos are sent only to TikTok, YouTube (Google) and Instagram (Meta) through their official APIs, subject to their own privacy policies.

Revoking access

Access can be revoked at any time in each platform's account security settings. For Google/YouTube, use the Google security settings page.

Data retention and deletion

The stored OAuth token is kept only on the studio's computer while the tool is in use and is deleted when access is revoked or on request. To request deletion of any data, email the contact below; requests are handled within 7 days.
